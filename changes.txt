     - Date format        : Y/m/d
     - Logo               : কোম্পানির লোগো আপলোড + "Show logo" টিক
     - QR code            : Show QR code টিক  +  ZATCA QR টিক (সৌদি ট্যাক্স QR)
     - Show barcode       : পছন্দ অনুযায়ী

================================================================================
  টেকনিক্যাল নোট  (ভবিষ্যতে কেউ এডিট করলে পড়ুন)
================================================================================
  এই লেআউটে কিছু জিনিস ইচ্ছাকৃতভাবে "অস্বাভাবিক" — সরাবেন না:

  1. পুরো ইনভয়েস একটি ১-সেল টেবিলের (.bm-sheet) ভেতরে।
     কারণ: এই অ্যাপের প্রিন্ট কনটেক্সটে শুধু <td> এর বর্ডার নির্ভরযোগ্যভাবে আসে।
     <div> বা <table> এলিমেন্টের নিজের বর্ডার ড্রপ হয় বা ডাবল হয়।

  2. আইটেম টেবিলে border-collapse: separate (collapse নয়)।
     কারণ: collapse মোডে Chrome প্রিন্টে <thead> এর উপরের বর্ডার মুছে ফেলে।
     সেপারেট মোডে টেবিলের border: 0, সব লাইন সেল থেকে আসে (নইলে ডান/নিচ ২px হয়)।

  3. @page { size: A4; margin: 5mm }  —  @media print এর **বাইরে**।
     ভেতরে দিলে Chrome ১ ইঞ্চি ডিফল্ট মার্জিন নেয়, ফলে ২ পেজ হয়ে যায়।

  4. পাশাপাশি বক্সগুলো flexbox (.bm-split / .bm-col), নেস্টেড টেবিল নয়।
     নেস্টেড লেআউট টেবিল প্রিন্টে ভুতুড়ে খালি কলাম তৈরি করছিল।

  5. .bm-stamp  —  flex: 1 1 auto; খালি ব্যান্ড।
     পেজের বাকি উচ্চতা টেনে নেয়, ফিজিক্যাল সিলের জন্য সংরক্ষিত। খালিই থাকবে।

  পরিবর্তনের পর সবসময় যাচাই করুন:
     chrome --headless --print-to-pdf=out.pdf file:///.../preview.html
     তারপর PDF এ "/Type /Page" গুনে দেখুন = ১
